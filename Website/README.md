# PHS DECA website

The site is a Vite-built, static multi-page chapter website for Parsippany High School DECA. It keeps the Blue Hour homepage opening, then links visitors to joining information, current dates, competition resources, and merchandise status.

See [MAINTENANCE.md](./MAINTENANCE.md) for the content workflow, source links, accessibility checks, and local commands.

Run it locally from this directory:

```bash
npm install
npm run dev
```
